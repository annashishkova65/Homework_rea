# Homework_rea

Учебные работы по Python в формате Jupyter Notebook. Здесь собраны практические задания, примеры анализа и визуализации данных, работа со связными списками и классификация с помощью нейросети.

## Как открыть

Для просмотра выберите нужный файл `.ipynb` на GitHub. Для запуска откройте его в Jupyter Notebook или загрузите в Google Colab и выполняйте ячейки по порядку.
